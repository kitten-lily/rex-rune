## Baseline and method

Surveyed all **seven** forks returned by the paginated GitHub forks API and all **12** published branches returned by their paginated branches APIs. Fetched every branch into `refs/remotes/harvest-<owner>/*`; compared against freshly fetched `origin/master` **da8da4044e4bba66ecd1c9b78413b57be18c969b** (v0.4.1, API 10–12). No contributor was contacted.

Recency is not novelty: kamleshkc2002's push at **2026-11-09 6:13:57 PM PST** points at our release history. Lily's latest push was **2026-11-09 10:54:24 AM PST**. Deleted topic branches (`settings-click`, `feature/inherit-cwd`, Activity/session progress) remain visible through merge ancestry on Lily's master.

`git log origin/master..<branch>` finds 95 unique non-ancestor commits (including merges); it does **not** prove 95 new changes. Adaptations change patch IDs, so `git cherry` alone is insufficient. Reviewed candidate diffs and current implementation, release notes and Phase 5/6 history. Every branch and every unique non-ancestor commit is accounted for below. Commits already ancestors of master are covered by their branch's ancestry verdict.
