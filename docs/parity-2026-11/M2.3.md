# M2.3 recovery: Settings search and navigation

Implemented initially on `00c07aa`, then rebased onto `628cb5d` (PR #59, including
`1315556`'s conditional-binding and exact-key-query fixes). The baseline gap report
and its counts are unchanged. This is a focused slice, not a claim that every
original M2.3 acceptance case is complete.

## Scope and provenance

- Adapted `settings_nav.rs`, `settings_shell.rs` and navigation tests from
  `cc8bdad` / `parity/w2-preserved-20261111`. Consulted its code/runtime Settings
  inventories; current PRODUCT/DESIGN and download policy take precedence.
- Search reads a row registry from the existing Settings kit's labels, helpers and
  section headings. No duplicated list of preference labels. It also finds each
  existing page by title and discovery aliases. Labels rank before helper matches;
  results are bounded to 40, with pointer selection and wraparound Up/Down.
- Enter/click visits a page and centers a found row. Its 2.4-second selection mark
  paints behind the content; the marked helper uses primary ink for legibility.
  The search keeps focus, supports no-results state, and Escape clears it.
- Eight existing sections, grouped in the beta's relative order, with authored
  20 pt icons in 22 pt tiles. Sidebar scrolling is independent of the page.
- Back/Forward buttons, Alt+Left/Right and mouse Back/Forward use a bounded,
  window-local Settings history (64 stops), retaining scroll offsets. New visits
  discard forward history; reopening via Settings, About or Updates resets it.
  Forms and anchored pickers retain their existing return paths, not history stops.
- PR #59's page, pinned filter, exact-key behavior and conditional binding coverage
  are retained. Global Settings search links to Shortcuts but does not index its
  actions. Only its key handler changes: Alt+arrows reach Settings history before
  TextInput moves its caret; Escape clears its own filter first, then any outer
  Settings search, then closes.
- Existing download folder and Downloads UI, remote consent, About/server facts,
  prompt navigation and #44 aliases/modes remain. No new saved fields or protocol
  requests; no theme/font/terminal-control/recorder/toolbar recovery.

## Deliberately deferred

No empty Themes section and no speculative subpage enum/stack. Existing panes,
tabs and notification switches stay where users already find them. Moving two
controls behind another click, or giving each notification switch its own empty
page, would not make a useful subpage. Meaningful status and Tabs/Panes subpages
belong with their actual settings in M3.4/M2.8; the visit/scroll history is reusable
then. The original “Notifications > Blocked > Back” case is therefore not claimed.

`sound` is a discovery alias for the existing Notifications page, **not** a sound
control. Search indexes labelled kit rows, not arbitrary footnotes, live values,
integration-agent custom rows, or Shortcuts actions. Repeated row labels on one
page resolve to the first row. The index is refreshed when a new search starts.
