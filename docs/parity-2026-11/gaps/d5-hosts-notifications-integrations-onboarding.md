# D5: Remote hosts, pairing, server page, notifications and sounds, integrations, onboarding and migration

Gap report for Rex Linux 0.6.0 (commit ad196ff, API 10-13) against Rex Beta 0.1.0 (1932) for macOS, domain D5. Inputs: beta specs b01, b06, b12 (plus b07, b08, b09, b10 where they touch this domain), Linux specs r01, r02 (r03 for menus), code inventory c04, the screenshots, the source, `vendor/rexrs/codegen/help.json`, AGENTS.md, PRODUCT.md and DESIGN.md. Screenshot references: `B###` is `rex-beta-ui-2026-11-10/screenshots/###-*.png`, `L##` is `rex-rune-2026-11-11/screenshots/##-*.png`. Paths are relative to the repo root.

## 1. Summary

Linux is well ahead of the beta on **connecting to hosts**: tailnet discovery with a Rex probe, SSH forwarding with a previewed one-time "Start personal server...", a listener-review form, edit/remove/default-shell per host, reconnect states, and a default-deny remote-control model with a pinned allowed set. It is also ahead on **agent integrations** (per-agent status, update/replace/remove, dry-run previews, OMP) and on **update checks** (signed metadata and channel-specific guidance, where the beta's Check for Updates shows nothing). Notification **plumbing** is at parity (tab activity words, desktop notifications for tabs out of view with click-to-focus, OSC 9/777).

Linux is missing or thin in four places:

1. **The Server page, pairing and server management.** Nothing shows the server's identity, version, uptime, tailnet address or listeners, and there is no Pair (QR) sheet. The server API already offers all of it (`server.status`, `server.version`, `server.tailscale.*`, `server.stop`). Only `server.status` is called today, and only by the discovery and SSH-setup probes (`src/tailnet.rs:274`, `src/ssh/setup.rs:109`), which read just its `listeners`; `server.version`, `server.stop` and `server.tailscale.*` are never called. The QR payload in B071 is only the plain `https://<host>-rex.<tailnet>.ts.net` address (decoded from the screenshot with zbarimg), so a read-only Server page with Copy and Pair is cheap. Writing controls (stop server, Tailscale enable/sign out/rename) collide with the attachment-only rule and need an explicit decision.
2. **Sounds and per-status notification control.** No sound at all, no volume, no per-status (Working, Blocked, Error, Done) channels, no status icons, no launcher badge, no activity popover, no tab mute. Linux has one flat list of four on/off switches.
3. **Onboarding and migration.** Linux has no first-run experience at all. The beta's five pages are Welcome, Appearance, Integrations and Permissions, Migrate, Finish. The Linux version must be a client-local flow (a session must never be created implicitly) and drop or replace the macOS-only parts (colour scheme, glass, TCC permissions).
4. **Form and settings craft.** The beta's sheets have a header (icon, title, subtitle), card-grouped rows and a divider-separated footer; Linux dialogs are title-only stacks of labelled fields with long grey helper paragraphs, a low-contrast placeholder, and several known defects (truncated discovery row, mono-less paths). Settings has no search, no history/subpages, no icon tiles and no groups, and is a 760x520 modal.

Where the beta uses macOS idioms, the Linux equivalents are: menu bar and Services become Commands plus the host chip (no global menu); the status-bar extra becomes an optional StatusNotifierItem later; Dock badge becomes a launcher-entry badge; TCC permissions become a notification-service health line; AutoFill and Writing Tools have no equivalent.

Status counts: linux-ahead 3, linux-only 9, missing 33, not-applicable 6, parity 6, partial 18.

## 4. UI quality deltas

Numbered, each with evidence and a fix in Rune terms. Palette tokens live in `src/app/theme.rs` (`ground()`, `card()`, `popover()`, `ink()`, `muted()`, `accent()`, `danger()`, `warning()`, `CARD_RADIUS`); never hard-code colours in views (DESIGN.md).

1. **Rows are flat, cards are absent.** Beta groups related rows into a rounded card (`#12161A` on `#0B0F13`) with a heading above and a footnote below; Linux draws bare rows on the panel with inconsistent dividers (r01 cross-cutting 1; L01, L03, L05, L14). Evidence: B053 vs L03, B005 vs L05. Fix: in `src/app/settings_view.rs` give `group()` (line 37) a `group_card(rows)` sibling that wraps rows in `card()` fill, `CARD_RADIUS`, 10 pt padding and inserts `divider()` (line 45) between children automatically, so no page decides dividers by hand.
2. **Section headers: bold 13 pt title vs letter-spaced caps.** Beta headings are `13 pt semibold #E1EAF1` with an optional 11 pt subheading (`Program Activity` + `How status from processes and agents is handled`). Linux uses `label_caps()` grey (`NOTIFY WHEN A PROGRAM`, `AGENTS`, `DEFAULT SHELL`). Fix: change `group()` to accept an optional subheading and use `medium(13.)`/`ink()`; keep caps only in popups (switcher, discovery) where they read as list labels.
3. **Settings is a short modal that both clips and leaves holes.** 760x520 (settings_view.rs:826-827); L07 is about 60% empty (content ends at about 100 px of 525), L04 clips 'Let agents name sessions' at the bottom edge with no fade (L05 and L15 sit tight to the bottom edge but are whole; the draft wrongly listed them as clipped). Beta is 816x850 with no clipping on its busiest page. Fix: size to `min(900, 0.9*viewport)` x `min(760, 0.88*viewport)`, content column max 560 centred like beta's 561 cards, and add a 12 pt bottom fade or a scroll shadow in the scroll `El` (line 811) so a cut row is never mid-control.
4. **No Server page and no status at a glance.** B005 puts identity, uptime, version, address, Copy and Pair in the first card of the first page; Linux shows an API revision on About only. Fix: new `src/app/server_page.rs` (below).
5. **Primary action alignment.** Beta right-aligns action buttons to the card edge (B054 `Add Remote Host...`, B061 footer); Linux left-aligns `Check again`, `Set up all detected...` and `Add host...` (L04, L05; integrations.rs:614,653; settings_view.rs:107). Fix: right-align via `justify_end()` and place the primary at the right end.
6. **Control vocabulary: stepper circles, segmented controls and pill buttons mix.** Beta uses only switches, capsules, popup buttons with a chevron badge, one slider and one 6-way picker. Linux mixes dark-ring steppers, segmented controls (`Notices`) and pills (L01). For this domain: replace the `Notices` segmented control with the six-position picker (below) and give Integrations a state chip ('Installed', 'Update available', 'Not installed') on the right instead of an `Install...` pill plus a status line (see 12).
7. **Switch semantics are not communicated.** Beta disables dependent switches visually (`Tailscale ...` rows at `#0D5BBA`) and hides the `Sound` row while `Play sound` is off; Linux disables sub-switches when Desktop notifications is off (settings_view.rs:198) but gives no hint why (L03 polish note). Fix: indent dependents by 16 pt under the parent and add a 11 pt helper 'Turn on Desktop notifications first' (muted) when disabled.
8. **Rows without helper text break rhythm.** `Starts working`, `Commit`, `Build date` have no helper, so the row is shorter and centred oddly (L03, L08). Beta rows always have either one line (39 pt) or a subtitle (45 pt) with fixed `min_h`. Fix: set `min_h(39.)` on `setting()` (line 14) and a fixed 45 when a detail exists.
9. **Dialog anatomy.** Beta sheets: icon + title + subtitle header, divider, grouped body, divider, footer. Linux dialogs (L18-L24) are a title and a stack of labelled fields, with the primary button directly under the last paragraph. Evidence: B061 vs L22. Fix: in `src/app/dialogs.rs` add `sheet(icon, title, subtitle, body, footer)` that wraps `modal_frame` (line 24) with a 64 pt header, 1 pt `white(0.06)` dividers (the same as the settings split, settings_view.rs:831) and a 16 pt footer inset; use it for Add host, Edit host, Client label, Connect to Rex and Add over SSH. Keep forms 338 pt wide only for yes/no confirmations.
10. **Placeholder and value are nearly the same colour; fields have weak focus.** L10, L22 (placeholder `my-host`, endpoint hint to the right edge) vs B061 (placeholder `#5B5F64`, 3 pt ring). Fix: placeholder `mix(muted(), ground(), 0.45)` and a 2 pt `accent()` focus ring on text fields (the buttons already have one, widgets.rs:59-60); add right padding 12 pt so a long placeholder wraps or truncates with an ellipsis.
11. **Diagnostics text is mixed with helper text.** L23 appends `Couldn't tell whether Rex listens there (https 443: HTTP error: 404 Not Found)` inside the grey paragraph; L24 puts 'Reachable from this device' at the same weight as the listener dump; paths wrap mid-word and are proportional. Fix: three tiers: status line (`WARNING` or `accent()` with a check/alert glyph), helper (muted 11 pt), and a monospace block (the terminal font family from `fonts.rs`, at 11 pt) for socket paths with a copy button. Put the probe error under a 'Details' `Collapsible` (rune-kit `collapsible.rs`).
12. **Integrations rows are verbose and repetitive.** L04 repeats 'Shares its skill at ~/.agents/skills/rex with ...' four times and a 5th redundant line for OMP; beta shows one footnote. Fix: render one shared-skill note under the group ('Codex, OpenCode, Pi and OMP share ~/.agents/skills/rex') in muted 11 pt, one-line status chip per row, and show agent glyphs (existing `CLAUDE`, `CODEX` and related `icon!` assets in theme.rs) as 16 pt row leading icons. File: `src/app/integrations.rs:486-575`.
13. **Discovery list defects.** L21: the `Added as shuvbot-rex` row truncates its name to `..` and overflows its metadata past the popup edge with no chevron; `shuvmbp-r...` truncates though there is room; metadata is right-aligned so tokens do not align; only REX SERVERS has a group icon; `Rex check failed` is plain grey. Fix in `src/app/discover.rs:187-276` and the popup row layout in `src/app/popups.rs`: give the name `flex-shrink 0` with `min_w` of its text, put metadata in a `min_w(0)` ellipsis column, move `Added as` into a trailing chip, give all three group headers an icon (SERVER, a network glyph, a moon/offline glyph) and render `Rex check failed` in `warning()`.
14. **Remote Hosts rows.** L05: `Remote control` rows sit flush-left and are not visibly under their host; the local host shows its shell and remote hosts do not; `rex do` is not code-styled; destructive `Remove...` is red-outlined on every row. Fix: wrap each host (header row + Remote control row) in one card (delta 1); indent `Remote control` 36 pt under the name; keep Remove... neutral in the row and put the red `Remove host` only in the confirmation (consistent with r03 'destructive items are never styled in menus'); format `rex do` with the mono style.
15. **Empty and error states.** Beta has a designed empty state (globe, title, one-line body, button) and a status row with a coloured glyph; Linux uses grey sentences ('Waiting for connection...', 'Tailscale isn't installed on this machine...') with no icon or action. Fix: a shared `empty_state(icon, title, body, action)` in `src/app/widgets.rs`, used by the discovery list, Remote Hosts and the Integrations 'rex not found' case.
16. **No status iconography for Notifications.** Beta's four status circles (blue, orange, red, green gradients with white glyphs) are the only colour on the page and carry the page. Linux has none, although tabs already show per-state words and `WARNING`. Fix: add `src/app/theme.rs` tokens `status_working()`, `status_blocked()`, `status_error()`, `status_done()` per palette (each a gradient pair or a single mixed tint), 24 pt circles with SVG glyphs (`DOTS`, `BAN`, `ALERT`, `CHECK` via `icon!`), reused in the Activity popover and tab pills.
17. **Onboarding has no equivalent surface.** Beta pages are centred, one idea per page, with a card, one primary and a skip link (B132-B137); Linux's first impression is a terminal (or, when the host has no session, a `Your workspace starts here` card with one button) under a toolbar of icons. Fix: see work item 11.
18. **Copy.** Beta: short, no jargon. Linux: `Applies the next time Rex sets up your agents`, `Visible on every host; reopen the app after editing`, 4-line Theme helper (L02). Fix the two in this domain: Client label becomes live (client.set_label) so the 'reopen' sentence disappears; the integrations toggle gets beta's footnote.
19. **Version formatting.** `v0.6.0` on Updates (L07) vs `0.6.0` on About (L08); the beta uses one form `Version 0.1.0 (1932)`. Fix in `src/app/updates.rs:134` and `about.rs:71`: one `format_version()` helper, mono for commit.
20. **Motion.** Beta switches, popovers and sheets animate natively; Linux already uses springs from `theme.rs` (`POP`, `SNAPPY`) for popups and modals; no delta except that the proposed sheet, picker and slider must use `pop_in()` and `SNAPPY` and never animate terminal content.
